# InkSpace — Frontend Blog Application

A responsive blog application built from scratch with **HTML, CSS and vanilla JavaScript** for the Frontend Development internship module.

## Features
- Responsive home page with editorial-style hero section and story cards
- Search stories by title, description or category
- Filter stories by Technology, Design, Lifestyle and Learning
- Register and log in (demo-only browser storage)
- Dashboard showing the signed-in user's stories
- Create, edit and delete blog posts
- Article reading view
- Newsletter form interaction (demo only)
- Data persistence with `localStorage`

## Pages / views included
1. Home / Explore
2. Login
3. Register
4. Dashboard
5. Create Blog

The article reading view is an additional feature.

## Run locally
1. Download and extract the ZIP.
2. Open the `frontend_blog_application` folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

No build tools or dependencies are required.

## GitHub upload
1. Create a new public repository on GitHub, for example `frontend-blog-application`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` (or push the folder using Git).
3. Copy the repository URL for your internship submission.

## Important demo limitations
This is a frontend-only learning project. Accounts and blog posts are stored in the current browser using `localStorage`; they are not secure and do not sync across devices. Do not use a real or reused password. A production application needs a backend, database, secure authentication and server-side validation.
